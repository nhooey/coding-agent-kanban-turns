Every response in a turn is kanban-shaped, as the {{plugin}} plugin teaches and checks it. A progress update between tool calls is one line whose state emoji show what is done, running and next. The final response is up to {{count.lists}} underlined, numbered lists of what is new this turn, in a fixed order, {{names.lists}}, each item's bold summary on its own line, then what earlier turns left open under {{roll-up.glyph}}, in full on an interval, otherwise as one count line. {{lists.decide.header}} items and their capital-lettered options, {{kinds.names}}, each read alone, with pros and cons; an answer that asks a question is answered in its item, never taken as a choice. `scripts/kanban.js` runs the plugin's core: the count line, the roll-up's draft and the reply lint. Load this skill only where the conversation holds no block opening "This block is the `{{plugin}}:{{skill.name}}` skill's format", which the plugin's hooks send.
