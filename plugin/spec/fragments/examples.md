## Worked examples

Each file in this skill's `examples/` folder is one of the {{plugin}} plugin's golden cases: a transcript of turns, each prompt and response as written, then what the plugin's core gives for it: what is still outstanding under {{roll-up.glyph}}, the count line, and what each item's `{{frees.label}}:` line frees. The plugin's tests run every case through its core and its lint, so each response holds the format as this skill gives it.
